Installation du logiciel Makeblock

⏱️~10 minutes 📊 Débutant

Ce que vous apprendrez

  • Comment télécharger et installer le logiciel mBlock
  • Configuration système requise pour votre ordinateur
  • Configuration initiale

Qu'est-ce que mBlock?

mBlock est le logiciel de programmation que vous utiliserez pour contrôler votre robot Makeblock. Il est basé sur Scratch, donc si vous avez déjà utilisé Scratch, vous vous sentirez comme chez vous. Vous glissez-déposez des blocs de code pour créer des programmes - aucun code compliqué à taper!

Le meilleur? Il fonctionne sur Windows, Mac et même les Chromebooks (version web). Donc pratiquement n'importe quel ordinateur que vous avez fonctionnera.

Si vous utilisez un ordinateur de l'école, vérifiez d'abord avec votre enseignant - vous pourriez avoir besoin des permissions d'administrateur pour installer le logiciel.

Configuration système requise

Avant de télécharger, assurez-vous que votre ordinateur répond à ces exigences:

  • Windows 7 ou plus récent / macOS 10.10 ou plus récent
  • Au moins 2 Go de RAM (4 Go recommandés)
  • 500 Mo d'espace libre sur le disque dur
  • Port USB (pour connecter votre robot)

Installation étape par étape

Télécharger mBlock

Rendez-vous sur le site officiel de Makeblock: mblock.makeblock.com

Cliquez sur le gros bouton « Télécharger ». Le site Web devrait automatiquement détecter votre système d'exploitation (Windows/Mac) et vous donner la bonne version.

Exécuter l'installateur

Une fois le téléchargement terminé (environ 200 Mo, donc cela peut prendre quelques minutes), trouvez le fichier d'installation dans votre dossier Téléchargements et double-cliquez dessus.

[Ajouter capture d'écran: icône du fichier d'installation]
Sur Mac, vous pourriez recevoir un avertissement de sécurité. Allez simplement dans Préférences Système > Sécurité et confidentialité et cliquez sur « Ouvrir quand même ».

Suivre l'assistant d'installation

L'installateur vous guidera tout au long du processus. Continuez simplement à cliquer sur « Suivant » et acceptez les paramètres par défaut - ils sont parfaitement bien pour ce dont nous avons besoin.

[Ajouter capture d'écran: étapes de l'assistant d'installation]
L'installation peut prendre 3 à 5 minutes. Moment parfait pour prendre une collation!

Premier lancement et configuration

Lorsque vous ouvrez mBlock pour la première fois, vous verrez un écran de bienvenue. Choisissez votre langue (français ou anglais) et sélectionnez le mode « Appareil » - c'est ce que nous utilisons pour les robots.

[Ajouter capture d'écran: écran de bienvenue mBlock]

Connecter votre robot

Branchez votre robot sur votre ordinateur à l'aide du câble USB. Cliquez sur « Connecter » dans le menu du haut, puis sélectionnez votre appareil (comme mBot ou mCore). Vous devriez voir une coche verte lorsqu'il est connecté avec succès!

[Ajouter capture d'écran: menu de connexion avec appareils]
Assurez-vous que votre robot est ALLUMÉ! C'est facile à oublier mais il ne se connectera pas s'il est éteint.

Tester votre configuration

Assurons-nous que tout fonctionne! Essayez ce programme super simple:

when green flag clicked play note (C4) for (0.5) beats

Cliquez sur le drapeau vert pour l'exécuter. Si vous entendez un bip de votre robot, félicitations! Tout est configuré correctement.

Problèmes courants et solutions

Le logiciel ne s'installe pas

  • Droits d'administrateur - Vous pourriez avoir besoin de permissions d'administrateur sur votre ordinateur
  • Antivirus - Désactivez temporairement le logiciel antivirus pendant l'installation
  • Espace - Assurez-vous d'avoir au moins 500 Mo de libre sur votre disque dur

Alternative: Version web

Vous ne pouvez pas installer la version de bureau? Pas de problème! Vous pouvez utiliser mBlock en ligne à ide.mblock.cc. Il fonctionne dans n'importe quel navigateur web et ne nécessite pas d'installation. Le seul inconvénient est que vous aurez besoin d'une connexion Internet chaque fois que vous voudrez coder.

La version web est parfaite pour les Chromebooks ou si vous utilisez un ordinateur partagé/scolaire où vous ne pouvez pas installer de logiciel.
