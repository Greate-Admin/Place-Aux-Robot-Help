Utilisation du capteur ultrasonique

⏱️ ~15 minutes 📊 Débutant 🔧 mCore requis

Ce que vous apprendrez

  • Comment connecter le capteur ultrasonique à votre carte mCore
  • Quelle extension utiliser et comment l'ajouter
  • Lecture des valeurs de distance dans votre code
  • Faire éviter les obstacles à votre robot

Qu'est-ce qu'un capteur ultrasonique?

Le capteur ultrasonique est essentiellement les yeux de votre robot. Il émet des ondes sonores (que les humains ne peuvent pas entendre) et mesure le temps qu'elles mettent à rebondir. À partir de cela, il détermine à quelle distance se trouvent les choses.

Pensez-y comme l'écholocalisation d'une chauve-souris, mais pour les robots. Plutôt cool, non?

Le capteur fonctionne mieux entre 3cm et 400cm. Plus près ou plus loin et il pourrait vous donner des lectures étranges.

Ce dont vous avez besoin

  • Votre robot avec carte mCore
  • Capteur ultrasonique (la chose bleue avec deux cercles argentés)
  • Un câble pour le connecter (généralement fourni avec le capteur)
  • Logiciel mBlock installé sur votre ordinateur

Configuration étape par étape

Connecter le capteur

Prenez votre capteur ultrasonique et cherchez les ports sur votre carte mCore. Ils sont étiquetés et généralement numérotés. Connectez votre capteur au port 3 ou 4 - ce sont ceux qui fonctionnent avec le capteur ultrasonique.

[Ajouter image: Capteur ultrasonique connecté au port 3 du mCore]
Assurez-vous que votre robot est ÉTEINT lorsque vous branchez des choses. C'est juste plus sûr comme ça.

Ouvrir mBlock et ajouter l'extension

Lancez mBlock sur votre ordinateur. Cherchez le bouton « Extensions » en bas à gauche - il ressemble à une pièce de puzzle ou un signe plus.

Dans la barre de recherche, tapez « mBot » ou « ultrasonic » et ajoutez l'extension mBot. Cela vous donne tous les blocs dont vous avez besoin pour travailler avec le capteur.

[Ajouter image: Menu des extensions dans mBlock avec mBot sélectionné]

Trouver le bloc ultrasonique

Une fois l'extension chargée, regardez dans le panneau de blocs à gauche. Sous la catégorie « Capteurs » (généralement bleu ou violet), vous trouverez un bloc qui dit quelque chose comme:

ultrasonic sensor [port] distance

Ce bloc renvoie un nombre - la distance en centimètres à ce qui se trouve devant le capteur.

Écrire votre premier programme

Faisons quelque chose de simple - un programme qui affiche la distance sur votre écran. Voici ce dont vous avez besoin:

when green flag clicked forever say (ultrasonic sensor [port 3] distance) for (1) seconds

Lorsque vous exécutez ceci, votre sprite vous dira constamment à quelle distance se trouve l'objet le plus proche. Agitez votre main devant le capteur et regardez les nombres changer!

Vous ne voyez rien? Assurez-vous d'avoir sélectionné le bon numéro de port dans le bloc (devrait correspondre à l'endroit où vous l'avez branché).

Faire éviter les obstacles à votre robot

D'accord, maintenant la partie amusante - faisons en sorte que votre robot fasse QUELQUE CHOSE avec ce capteur. Voici une configuration de base pour éviter les obstacles:

when green flag clicked forever if (ultrasonic sensor [port 3] distance) < [20] then move backward at speed [100] for [0.5] seconds turn right [90] degrees else move forward at speed [150]

Ce que cela fait: Le robot avance normalement, mais s'il s'approche à moins de 20cm de quelque chose, il recule et tourne à droite pour l'éviter. Simple mais efficace!

N'hésitez pas à jouer avec ces nombres. Essayez différentes distances, différentes vitesses, différents angles de virage. Voyez ce qui fonctionne le mieux pour votre robot et votre arène de compétition.

Problèmes courants et comment les résoudre

Le capteur ne fonctionne pas / renvoie toujours 0 ou 400

  • Vérifiez vos connexions - Le câble est-il bien branché?
  • Numéro de port - Assurez-vous que le port dans votre code correspond au port physique
  • Essayez un autre port - Parfois, les ports peuvent être capricieux

Obtention de lectures étranges/saccadées

  • Ajoutez un petit délai - Mettez un « attendre 0.1 seconde » dans votre boucle
  • Moyenne de plusieurs lectures - Prenez 3 mesures et utilisez la valeur du milieu
  • Vérifiez les obstacles - Des fils ou des pièces desserrés pourraient bloquer le capteur

Conseils d'expérience

Après avoir utilisé ces capteurs dans plusieurs compétitions, voici ce que j'ai appris:

  • Le capteur a une zone de détection en forme de cône. Il ne voit pas seulement droit devant - il voit aussi un peu sur les côtés. Gardez cela à l'esprit lors de la navigation dans des espaces restreints.
  • Les surfaces brillantes ou inclinées peuvent perturber les lectures. Les ondes sonores rebondissent sous des angles étranges.
  • Les matériaux mous (comme le tissu ou la mousse) absorbent les ondes sonores. Votre robot pourrait penser qu'il n'y a rien là!
  • En compétition, testez votre robot sur la surface réelle de l'arène si vous le pouvez. Différents sols peuvent affecter la précision du capteur.
Vous voulez faire quelque chose de sophistiqué? Vous pouvez utiliser deux capteurs ultrasoniques (un de chaque côté) pour que votre robot suive les murs ou navigue dans les corridors. Il vous faut juste deux ports!
